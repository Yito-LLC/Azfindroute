This page needs a web server. Opening it straight from the folder blocks the sign-in code from loading, so the page stays blank. Run python -m http.server 8000 in this folder (or use the VS Code Live Server extension), then open http://localhost:8000/index.html.

    Bus stops by school

    Enter your address and choose a school to pin its nearest bus stop. Click any dot for routes and times.

    Parent access

    Parents do not have a school email, so add them here. They get an invite email with a sign-in link, and once they open it they can set a password and sign in whenever they like.
